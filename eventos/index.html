O que desenvolvemos

Do conceito à informação que orienta a montagem.

Cada evento exige uma configuração própria. Organizamos a proposta visual, os elementos da estrutura e os materiais previstos para que o cliente tenha uma base clara para planejar e executar seu projeto.

Layouts e apresentações

Implantação, composição arquitetônica e modelos 3D para visualizar as estruturas no conjunto do evento.

Caderno de projeto

Detalhamento para montagem

Detalhes e orientações gráficas das estruturas individuais, conforme o escopo definido com o cliente.

Escopo de projetos: palcos, bases e acessos, camarotes, house mix, torres de delay, pavilhões, coberturas, portais, backdrops, tendas e áreas de apoio.

Como trabalhamos

Um projeto organizado para quem planeja e monta.

01 / Entendimento

Configuração do evento

02 / Desenvolvimento

Layout e modelagem

03 / Entrega
